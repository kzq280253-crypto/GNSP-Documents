# GNSP Official Documents Repository

**寰宇数字仿真世界平台（Global Nexus Simulation Platform, GNSP）官方文件库**

This repository hosts the official governing documents of the GNSP, established under United Nations General Assembly resolution A/RES/84/206 (2029-09-27) and UNESCO resolution 44 C/Res. 118 (2028-06-14).

Official documents:

- `A_RES_84_206.md` — UN General Assembly resolution establishing GNSP (2029-09-27)
- `UNESCO_44C_Res_118.md` — UNESCO 44th General Conference resolution (2028-06-14)
- `Singapore_Framework_Agreement.md` — Founding framework agreement signed in Singapore (2027-11-15)
